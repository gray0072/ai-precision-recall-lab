# 05 — Architecture

The code rules are the `ivan` repo's (`D:\Projects\my\ivan\AGENTS.md`, "Code is organised into folders by meaning"), applied to a repo that holds **one game at its root**. The rules themselves are restated in [AGENTS.md](../../AGENTS.md); this file is the concrete layout.

## 1. Stack

- HTML5, CSS3, vanilla JavaScript (ES2017+), Canvas 2D, Web Audio. **No build step, no package manager, no framework, no third-party libraries** ([ADR-0001](../adr/0001-static-vanilla-js.md), [ADR-0003](../adr/0003-hand-drawn-canvas-charts.md)).
- **Plain scripts, not ES modules**, so the game opens from `file://`: each file defines its globals; `index.html` loads them in dependency order.
- Node (20+) only for tests and tools, never for the game.
- Deployed as static files to GitHub Pages; an installable PWA.

Rules that go with it (from `ivan`): every file starts with a short header comment (what it is, who uses it); one file, one concern; split a file that passes about 1 000 lines; data is separate from code; gameplay numbers only in `constants.js`; when files move, update this tree in the same change.

## 3. Load order

`index.html` loads, in this order: `constants.js`; `data/` (icons, scenarios, contracts, upgrades, glossary, quiz, coach, lang-ru, lang-sv); `core/` (utils, rng, events, i18n, storage, audio, input, cursor, icons, update); `sim/` (state, model, stream, metrics, contract, incidents, review, topk, sandbox, demo); `campaign.js`; `art/`; `render/`; `ui/`; `game.js` last. Every local `<link>` / `<script src>` carries `?v=N`, bumped whenever that file changes.

## 4. State and events

- **Shared state** lives in `sim/state.js` as plain globals (`State.run`, `State.belt`, `State.pile`, `State.threshold`, `State.review`, `State.difficulty`, `State.screen`); other files read and change it there.
- **The logic never draws, plays sounds or shows messages.** It emits named events through `GameEvents` (`core/events.js`): `itemArrived`, `itemDecided {item, outcome, money}`, `goalChanged {state}`, `incidentWarning {kind, inS}`, `incidentStarted`, `driftAlert {psi}`, `outbreak`, `deskFull`, `retrainDone`, `contractEnded {result}`, `purchase {upgrade}`. `ui/sounds.js` turns them into sounds; `ui/hud.js` and `game.js` into banners and screens. With nothing subscribed the logic runs silent and headless (tests, `tools/balance-check.js`).
- **The main loop stays thin:** each frame (`requestAnimationFrame`, limited to 60 fps) `game.js` reads the input into the threshold(s), calls `Stream.update(dt)`, `Review.update(dt)`, `Incidents.update(dt)`, `Contract.update()` in this order, then `Render.frame()` and, when dirty, the live panel and the charts.
- **Determinism:** all randomness comes from `core/rng.js` streams seeded per attempt (02 §2.2); `Math.random` is not used in `sim/`.

## 5. Storage

Every key starts with `prLab.` (the Pages origin `gray0072.github.io` is shared with other apps: never `localStorage.clear()`, remove only own keys). Reads and writes are in try/catch; a missing or broken value falls back to defaults.

| Key | Value |
|---|---|
| `prLab.lang` | `en` / `ru` / `sv` |
| `prLab.sound` | `on` / `off` |
| `prLab.difficulty` | `easy` / `medium` / `hard` |
| `prLab.campaign.v1` | `{ money, upgrades: [ids], contracts: { C01: { easy: { stars, best }, … } }, quiz: { C01: true }, coach: [ids], lent: [], cheated }` |
| `prLab.sandbox.v1` | the sandbox's knobs |

A new save format gets a new key suffix (`.v2`) and a migration from the old one.

## 6. PWA and updates

- `manifest.webmanifest`: `name` "AI Precision Recall Lab", `short_name` "PR Lab" (≤ 12 chars), `description`, `start_url` / `scope` `"./"`, `id` `"/ai-precision-recall-lab/"` (absolute on purpose: a relative `id` resolves against the origin and would clash with every other app on `gray0072.github.io`), `display` `fullscreen`, `theme_color` / `background_color` `#0d1b2a`, icons `icon-192.png` + `icon-512.png` (`any`) and `icon-maskable-512.png` (`maskable`), all with `?v=N`.
- Static texts in `index.html` are `[data-i18n]` elements whose English inner HTML is the key (`core/i18n.js` `applyDom`); `tools/i18n-check.js` reads them too.
- `<head>`: the viewport meta `width=device-width, initial-scale=1.0, maximum-scale=1.0, user-scalable=no, viewport-fit=cover`, `mobile-web-app-capable`, `apple-mobile-web-app-capable`, favicon `icon.svg?v=N`, manifest, `apple-touch-icon`, `theme-color`, a `description` and Open Graph tags (`og:image` with the absolute URL of `screenshot.png` from I07, when the screenshot exists).
- `core/update.js` (`AppUpdate.watch(() => idle)`, idle = the start screen or the map): on every return to the foreground and once an hour it fetches `index.html`, compares its `?v=N` links with the running page's, and reloads at the next idle moment.

## 7. Testing

- **Unit tests (Node, no browser):** `node --test tests/*.test.js`. `tests/load.js` loads `constants.js`, `data/*.js`, `core/utils.js`, `core/rng.js`, `core/events.js`, `sim/*.js` and `campaign.js` (the ones that exist, in load order) into one `vm` context and returns their top-level declarations; values from it belong to another realm, so copy arrays (`Array.from`) before `deepStrictEqual`. They cover at least:
  - metrics on hand-made matrices (every formula of 02 §3.2, the empty-denominator rules);
  - ROC AUC equals the Mann–Whitney statistic; for 20 000 samples with `d'` = 2 the AUC is within 0.01 of `Φ(√2)` = 0.921; ROC is monotone; recall never rises with the threshold;
  - AP on a known small example (the scikit-learn value);
  - Platt scaling recovers `a = d'/γ`, `b = logit(π) − d'β/γ` within tolerance;
  - the cost-optimal threshold `p*` for the contracts' prices; the hindsight-best search finds the known optimum on a crafted stream and respects goals and the outbreak allowance;
  - a base rate shift leaves recall and FPR (in expectation) unchanged and moves precision as predicted; drift lowers the measured AUC; PSI > 0.2 after a 1.2 shift;
  - the review queue respects capacity; top-k metrics on a known query;
  - determinism: the same seed gives the same stream.
- **Balance:** `node tools/balance-check.js [--contract C05] [--difficulty hard]` plays each contract headless at t = 0.05, 0.10, …, 0.95 and at the hindsight-best, and prints money, goal met, stars; every contract must allow ★★★ on every level with the upgrades a normal campaign has by then (listed per contract in its output).
- **Browser checks:** `node --experimental-websocket tools/cdp.js <steps.js> [out-dir]` (from `ivan`; steps files live in a temp folder, not in the repo): boot on a phone (portrait and landscape) and a desktop, start C01, drag the threshold, take screenshots, report page errors. Keep runs short.
- **Translations** (from I07, when RU and SV are added): `node tools/i18n-check.js .` before every commit that touches texts; texts passed to `tr()` by variable (data tables) are checked by hand.
- **Icons:** `node tools/icons-build.js . --check` fails when `data/icons.js` is out of date.

## 8. Deployment

- GitHub repo `gray0072/ai-precision-recall-lab` (public), **Settings → Pages → Deploy from a branch → `main` / (root)**. No workflow, no build: pushing to `main` deploys. `.nojekyll` at the root.
- Live URL: `https://gray0072.github.io/ai-precision-recall-lab/`. All links are relative (the site lives under a subpath).
- Optional later: a CI workflow that runs `node --test tests/*.test.js`, `tools/i18n-check.js` and `tools/icons-build.js --check` on pushes (the game itself needs no CI).
